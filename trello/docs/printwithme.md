https://app.printwithme.com/print/
1. Select a printer
2. Type in Thinkspace as the location
3. Click "start a print job here"
4. Upload a document
5. Press "Apply a discount code"
6. Type in the staff promo code
7. Submit; the application will give you a code — write it down
8. Go to the printer
9. Select "secure release"
10. Type in the code and print
