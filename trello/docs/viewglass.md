ViewGlass is the automatic dynamic tinting system for the external windows throughout the Lake Union Building. Tint is controlled by roof sensors plus a pre-set schedule to pick optimal tint per zone, so windows tint automatically through the day. You can override temporarily with the ViewGlass app. Permanent schedule changes go to the ViewGlass rep.

**Granting access:** Thinkspace staff have access to all tint zones and can adjust an office's tint for a member temporarily — most often for Office Divvy members. Members are not automatically granted access; Private Office and Dedicated Desk members can request it. To give access, email the ViewGlass rep with name, email, and zones needed. Rep: Alex Palomarez, alex.palomarez@view.com. Zone map is a linked Drive file.

**Member setup (from the welcome email):** 1) Download View's *Dynamic Glass* app (blue icon; Apple App Store / Google Play). 2) In Settings enter the IP address 50.251.196.13 (include the dots). 3) Wait for the initial server connection (app can run in background). 4) Settings icon bottom-right → Login. 5) Login = the user's assigned login (lower case); password = the shared app password (lower case) — see 1Password. iPhone and Android user guides are linked from view.com.
