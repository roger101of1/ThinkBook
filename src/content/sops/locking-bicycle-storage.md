## Purpose
Where to find the code for the locking bicycle storage, and how to handle it.

## SOP
The bicycle storage is secured with a combination lock. The code is **not written here**: it is **in 1Password** (the Trello card also shows it, so treat the card as sensitive and do not share it). Look the code up in 1Password when a member asks for bicycle storage access, give it to the member in person rather than by email or text, and never post it on a sign, in chat, or in any document. If the code is ever changed, update the 1Password entry the same day so the front desk is never giving out a dead code.
