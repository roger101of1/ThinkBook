## Purpose
How doors are locked at each location, where every code is recorded, how to handle a member who is locked out, and how to add or remove a code on the Redmond MyQ call box. No codes appear on this page on purpose; they live only in the Door Codes sheet and 1Password.

> **Warning:** Never write a door, lockbox, office, conference-room, or master code anywhere except the Door Codes sheet or 1Password. Never send a code by email or text unless the process below says to. **Never give out the master code** to anyone.

## SEA (Seattle)
- Seattle has **all keypad locks**, or members use a **Door App**.
- **Hannah will update you** on how Seattle door access works. Ask her during your first week.
- The **Haystack** conference room has a keypad code recorded in the conference-room code log (Tab 3 of the Door Codes sheet). The Seattle **Storage Room uses a Latch lock**.

## RED (Redmond): where codes live
1. **Master codes and all other codes are in the Operational Directory.** The direct link is the **Door Codes** sheet (Links section).
2. The **office master codes are also saved in 1Password.**
3. The **Locked out Lockbox Code** sheet (Links section) is a separate log for the lockbox by the first-floor elevator.

Rules printed on the sheet that you must follow:
- **GENERATE NON-SEQUENTIAL CODES.** Member codes are 4-digit, 9000-series, and must not run in sequence.
- **NEVER GIVE OUT THE MASTER CODE.**
- **"Each time the code changes we need to record it as a NEW entry. Do not remove the old entry so we can ensure we don't reuse old codes."** Add a row; never edit or delete an old one.

## RED: when a member is locked out
1. The member emails **Lockedout@thinkspace.com**.
2. After someone has emailed, you **update the code on the lockbox by the elevator on floor 1** and give the member the new code.
3. Record the change in the **Locked out Lockbox Code** sheet as a **new row** with **Date, Code, Member Who Requested, Code Creator**. The sheet keeps every past code (one row is marked "RESET on 1/2/26") so that old codes are never reused.
4. Never write the lockbox code anywhere other than that sheet.

## RED: adding or deleting a MyQ call-box code
These steps are on Tab 1 of the Door Codes sheet. Bracketed items are values you look up in the sheet or 1Password; none are printed here.

**Add a code (new member)**
1. Pick a new **non-sequential 4-digit 9000-series member code** that is not already in Tab 1.
2. At the MyQ keypad, enter the **[Master Code]**.
3. Press **"L"**.
4. Enter the **[Location Code]** (for example, 01).
5. Press **"L"**.
6. Enter the **[New User Access Code]**, which is the same as the member code you chose.
7. Add a new row to Tab 1: Created By, Company, Member Code, the system-generated MyQ Code, and up to two MyQ Access Phone numbers. Send the member the "Redmond: MyQ Callbox" canned response (see the Canned Responses SOP).

**Delete a code (member moves out)**
1. Enter the **[Master Code]**.
2. Enter the **[Location Code]** (01).
3. Fill in the **Move Out Date** on the member's row in Tab 1. Do not delete the row.

**Changing the default master code**: the sheet documents the sequence (factory default, then 1, then the new master). This is done by a manager only; the current master is in 1Password.
