## Purpose
The set of bookmarks every Hospitality Coordinator should have on the laptop bookmarks bar, with what each tool is for. Set these up on Day 1.

## The bookmarks

| Bookmark | URL | What it is for |
|---|---|---|
| **Deskworks** | https://thinkspace.satellitedeskworks.com/user-search?user=2959&center=12&redirect=%2Fprofile | Member portal and billing. |
| **Yardi (Kube)** | https://09814think.yardione.com/Account/Login?ReturnUrl=%2F | Contracts (and conference room bookings). |
| **1Password** | https://start.1password.com/signin?l=en | Password manager. Every login and code lives here; never write them anywhere else. |
| **Trello** | https://trello.com/u/hannahmadgett1/boards | Task boards, including this onboarding board and the Move-in & Move-out boards. |
| **PilotoMail** | https://app.pilotomail.com/thinkspace/admin/651f2a58176c30c4cc649656/mail | Virtual-office mail handling. |
| **Humanity** | https://thinkspace.humanity.com/app/ | Staff scheduling. |
| **Sales Phone Inquiry** | https://thinkspace.com/sales-phone-inquiry/ | The form you fill in when a sales inquiry comes in by phone. |
| **Brivo** | https://access.brivo.com/ | Door access system (members' passes and building doors). |
| **Arlo Cameras** | https://www.arlo.com/en-us/login | Security cameras. **Runs on Ziply** (internet). |
| **PipeDrive** | https://thinkspace.pipedrive.com/pipeline | CRM: sales pipeline, tours, terminations. |
| **Dropbox Sign (esignature)** | https://app.hellosign.com/account/logIn | E-signature for documents. |
| **Skynet Voicemail for Frontdesk** | https://nms1.skynetbb.com/portal/ | Front desk voicemail portal (phones). |
| **HVAC IVU.Thinkspace.com** | http://IVU.Thinkspace.com | HVAC controls. **Runs on Comcast** (internet). See the HVAC IVU SOP for login. |
| **C3Scan Mail App** | https://c3scan.thinkspace.com/admin/login?redirect=%2Fadmin%2Fdashboard | Mail scanning app. |

## Steps

1. Open Chrome on the laptop and show the bookmarks bar (Ctrl/Cmd + Shift + B).
2. Add each URL above as a bookmark, using the bookmark name in the table.
3. Log in to each tool once with the credentials in **1Password** so you know the login works. Ask your trainer if any login is missing from 1Password.

> **Note:** Arlo runs on the Ziply internet connection and the HVAC IVU site runs on the Comcast connection. If one of those tools is unreachable, check that provider's outage map first (Outage Maps section of the Operational Directory).
