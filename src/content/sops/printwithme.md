## Purpose
How you, as a Thinkspace team member, print a document for free through the PrintWithMe web app using the staff promo code, and release it at the printer.

## Before you start

| Item | Value |
|---|---|
| Web app | [app.printwithme.com/print](https://app.printwithme.com/print/) |
| Location to enter | **Thinkspace** |
| Staff promo code (Employees Only) | **see 1Password** (or ask your manager) |

The Employees Only code lets the team print a document at no charge by entering the staff password in the **Promo Code** field. It is for staff use only, so do not share it with members.

## Steps

1. Open [app.printwithme.com/print](https://app.printwithme.com/print/) and **select a printer**.
2. Type in **Thinkspace** as the location.
3. Click **"Start a print job here"**.
4. **Upload** the document you want to print.
5. Press **"Apply a discount code"**.
6. Type in the **staff promo code** (see 1Password).
7. **Submit.** The application gives you a release code. **Write it down.**
8. Walk to the printer.
9. Select **"Secure release"** on the printer.
10. Type in the release code and print.

> **Warning:** the release code from step 7 is the only way to get your job out of the printer. If you lose it you will need to submit the job again.
