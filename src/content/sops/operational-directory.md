## Purpose
The Operational Directory is the Google Sheet that indexes every SOP and reference document for both Redmond (RED) and Seattle (SEA). This page explains what it is, how it is organised, and how to find what you need in it.

## What it is

- A single Google Sheet (link below) that acts as the **index of all SOPs**: roughly 300 rows across several tabs.
- Each row is a document name with a link to the SOP, guide, log or template it points to.
- It covers both locations. Some sections are RED-specific, some SEA-specific, and the Seattle tab has its own numbered structure.
- Some rows in the sheet contain vendor logins (PrintWithMe, Stamps.com, FedEx).

> **Warning:** Credentials that appear in the sheet must never be copied into any other document, chat or SOP. Use **1Password** for anything you need to log in with.

## How it is organised: the tabs

| Tab | What it is for |
|---|---|
| **Operational Directory – Redmond & Seattle (current)** | The main, current index. Organised by topic section (listed below). Start here. |
| **Operational Directory Seattle (numbered index)** | Seattle's own index, numbered by section (1, 3, 5, 5.6, 6.5, 6.8, 7.6, 8.1, 9.8, 10.8, and so on), plus Member-facing, Building, Ops and Product sub-tabs. |
| **OLD Redmond directory ("DO NOT USE ME I AM OLD")** | Legacy Essensys / Nexudus / Shoretel era content. Ignore except as history. |

## How to find things

1. Open the Operational Directory sheet (link below).
2. Pick the tab: the **current Redmond & Seattle** tab for most things, the **Seattle** tab for SEA-specific building, ops and member documents. Never use the OLD tab.
3. Scan the **section headers** in the left column to find the topic (for example Building Security, Printer, YARDI).
4. Use **Ctrl/Cmd + F** in the sheet to search a keyword ("Brivo", "parking", "refund") if you are not sure of the section.
5. Click the row's link to open the document.
6. If you cannot find an SOP, or a row says it still needs to be written (like Latch on the Seattle Building tab), ask your manager rather than guessing.

## Quick checks
- Right tab? Current Redmond & Seattle for most things, Seattle tab for SEA-only, never the OLD tab.
- Section first, then row name, then Ctrl/Cmd + F.
- Saw a login in a row? Leave it there; use 1Password and never copy it anywhere.
